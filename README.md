## Olá, eu sou Alice Fernandes! 👋

**`Desenvolvedora FullStack `**

Concluí o ensino médio no IFPB, com o curso técnico em informática. Atualmente, estou cursando Análise e Desenvolvimento de Sistemas no IFPB (Campus Santa Rita). Descobri minha paixão pela programação ainda no curso técnico, encantada com a liberdade de criar qualquer coisa através do código.

Com um histórico profissional que une design, marketing e administração, desenvolvi uma forte base em organização, análise de dados e resolução de problemas. Atualmente, aplico essa visão multidisciplinar para criar aplicações bem estruturadas, aplicando rigorosamente princípios SOLID e Design Patterns, unindo processos organizacionais eficientes a interfaces bem projetadas.
